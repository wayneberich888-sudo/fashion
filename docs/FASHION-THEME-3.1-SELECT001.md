## 必须核验的当前兼容性

所有证据必须优先使用主题官方站、官方文档、官方 changelog、官方 demo 或 WordPress/WooCommerce 官方资料。

至少核验：

1. 当前主题是否持续维护；
2. 与当前 WordPress / WooCommerce / PHP 8.3 的兼容声明或最新版本状态；
3. Elementor / Gutenberg / 自带 Builder 的依赖方式；
4. 目录模式或隐藏购物车/结账能力；
5. 商品归档/分类/品牌/搜索结果统一模板能力；
6. 商品详情模板能力；
7. 手机端 Header / Mega Menu / 搜索入口能力；
8. 原价 + Sale Price 展示；
9. 是否有可复用的倒计时能力，若无则明确标记需插件；
10. Blog / Editorial / Lookbook / Portfolio 类内容模板是否适合穿搭精选；
11. 与即时搜索插件（优先 FiboSearch）集成风险；
12. 与图片评价插件的潜在冲突；
13. 数千 Simple Product 场景下的性能风险；
14. 主题锁定风险；
15. 购买价格、授权模式、更新/支持周期。

至少选择每个候选 1 个最接近本项目定位的官方 Demo，形成三组对照证据。

每个候选至少覆盖：

- 首页；
- 商品列表/分类页；
- 商品详情页；
- 移动端导航/搜索；
- Blog / Editorial / Lookbook 类页面（如有）。

允许使用官方 Demo URL + 截图说明或文字证据；不得仅引用营销首页的一句话结论。
